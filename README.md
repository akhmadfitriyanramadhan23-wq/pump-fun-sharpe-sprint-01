A clean launch sniper for the Pump.fun Sharpe Sprint: it buys only fresh, organic-looking launches (at least 6 distinct non-creator buyers in the first 3 slots, creator buy capped at 1.5 SOL, no creator selling) and exits fast and mechanically — 70% off at +4%, the rest to +25% or a +2% floor, losers cut at −12%, never held past 6 slots. Many small, similar trades for a steady hourly Sharpe instead of one lucky moonshot. Dev-window backtest: net +0.119 SOL, 119 fills, 52 mints, max drawdown 0.44%.

node main.ts
